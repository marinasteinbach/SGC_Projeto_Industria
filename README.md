# SGC_Projeto_Industria
## Descrição do Problema
Restaurantes com falta de automatização na baixa do estoque, fazendo isso manualmente, estando sujeito a erros de quantidade e dificuldade na checagem da necessidade em reposição dos ingredientes
## Solução
 O sistema SGC promete automatizar a baixa no estoque, em cada baixa ele verifica se a reposição de itens é necessária, se o sistema ver que um item chegou no mínimo, um alerta é enviado.
 ## Tecnologias Utilizadas
 - HTML/CSS/JS
 - Node.js/Express 
 - SQLite
